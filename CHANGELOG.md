# CHANGELOG

## 2026-11-15
- Initial implementation (data, features, forecasters, calibration, metrics, tests).
- Fix: float32 tolerance in grid quantile search (unit test exposed 1-grid-step discrepancy).
- Data-quality fix (before any full experiment): runs of >=24 identical readings (stuck meters,
  incl. constant non-zero values) are now treated as missing (previously only zero runs). Found via
  smoke-test diagnostics: Lamb-site meters flat-lined at 0.0002-0.0046 kWh in 2017 produced
  normalised errors of ~80x. BDG2 buildings after filter: 984 -> 842; UCI 316 -> 315.
- Training-only filter: drop rows with normalised target y/s > 20 (meter restarts after outages).
- Onboarding windows drawn only where >= 80 % of hours are valid (all methods identical).
- HSC-CQR moved out of the ablation-only block so that it is evaluated in all experiments.
- (Before full run) Added same-score competitors for HSC-CQR: Self-CQR (self-only conformal on CQR scores,
  fallback to pooled CQR) and ACI-CQR (ACI on CQR scores, gamma tuned LOBO). Added component ablations
  for HSC-CQR (-stage, -kNN, -shrink). Stage curves now also store the median relative IS.
  Reason: quick-mode check showed self-only calibration to be a strong competitor on absolute scores;
  a fair test of HSC-CQR requires the same competitors on CQR scores. Quick-mode outputs deleted
  (verification only; regenerated by `--mode quick`).
- Evaluation fix (during full run, before any result was used): hours at which no forecast can be
  issued (the building's whole 7-day scale window missing; only possible in a few windows) were counted
  as misses (coverage) and produced NaN interval scores for 3 BDG2 building-seed cases. Now every method
  is evaluated on the common set of hours with observed truth and finite intervals; point metrics use the
  same mask. New unit test. All result parts deleted and recomputed (trained models reused from cache).
- Operational: two parallel experiment processes caused OpenMP thread oversubscription (LightGBM/torch
  spin-waiting; no progress for 33 min). Reverted to one sequential process. No results affected.

## 2026-11-16 (after session-limit resume)
- Prior-art audit (agents + author verification; REVIEW/pre_review_audit.md): the pseudo-count shrinkage
  mechanism is not new (Jeon 2026 donor+local mixture for new solar stations; Shahid 2026; Rafe & Das 2026;
  Zhang et al. 2024); GHCP (Mallick et al. 2026) and TQA (Lin et al. 2022) are close principled
  counterparts. Contribution re-scoped (no claim of a new mechanism); introduction and related work rewritten;
  17 verified references added.
- Added calibration-only baselines from the closest prior art: GHCP-CQR, QShrink-CQR (regularised Mondrian,
  lambda by LOBO), TQA-B-CQR. Added the recommended simplest variant (HSC simple / HSC-CQR simple: uniform
  prior, no stage matching, kappa by LOBO) and a model-agnostic check (CQR (MLP), HSC-CQR (MLP)).
  Pre-registered primary comparison remains HSC-CQR; the simple variant is reported as secondary.
- Journal facts updated: current publisher panel 66 days submission→acceptance (older snapshot 86 d);
  APC USD 5,290; JIF 18.3 (JCR 2026); author-guideline details (abstract <=250 words, highlights optional).
- Operational: container restart wiped data/raw (re-downloaded automatically); training-only mode added so
  all trainings are cached before one consistent calibration pass with the final code.
- Code-audit fixes (REVIEW/code_audit.md), all before the final calibration pass:
  (1) NaN-safe neighbour search with explicit self-exclusion (Major: NaN descriptors made kNN arbitrary and
  let a LOBO pseudo-target select itself; affected leave-site-out folds); (2) prior averaged only over buildings
  with scores in the stage bin (empty bins previously acted as mass at +inf); (3) score grid extended to 500·s
  (4,000 points) and own-quantile existence decided from counts for Self-*/QShrink fallbacks; (4) ACI empty-set
  convention (smallest observed score) instead of an inverted interval; (5) TQA-B with the original
  lambda-scaling of the budget and +inf point; (6) QShrink lambda tuned on the full kappa grid (incl. 0, inf)
  with a matching LOBO score-weighted pooled radius; (7) ACI gamma grid extended to {0, 1e-4, 2e-4, ...}
  (pre-registration deviation: the lower grid edge was hit in 7/10 runs); (8) mis-specified ablations removed
  (abs 'fixed-kappa' identical to tuned in 6/10 runs; '-kNN -stage' not re-tuned) and replaced by
  'HSC-CQR fixed-κ' (simple variant, κ = 168 h, = donor-local mixture with fixed pseudo-count);
  (9) all tuning tables stored in run_info. Four new unit tests. All result parts recomputed.
